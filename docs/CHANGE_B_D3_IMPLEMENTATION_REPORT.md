## 1. Выполнено фактически

### 1.1. Что изменено

Обработчик `ОбработкаПроведения` переписан по схеме «два режима + отказ при неоднозначности»:

| Ситуация | Поведение |
|---|---|
| ТЧ `Компоненты` непустая, шапка пустая | Режим A: проверка всех строк, затем движение `Приход` по каждой строке |
| ТЧ непустая и шапка заполнена | Отказ: «Wareneingang: заполнены и табличная часть Компоненты, и реквизиты шапки Komponenten/Menge - источник движений неоднозначен.» |
| ТЧ пустая | Режим B (legacy): прежние проверки шапки и одно движение — код сохранён без изменений |

Дополнительно:

- проверка выполняется по всем строкам **до** создания движений; при любой ошибке `Отказ = Истина` и `Возврат` — частичных движений не возникает;
- сообщения по строкам содержат номер строки (`Zeile N`);
- `Движения.Bestaende.Записывать = Истина` выставляется только в ветке, где движения действительно создаются;
- блокировки не добавлялись, порядок и смысл D10b не менялись;
- модуль `Verbrauch`, минимальные остатки и проверки `Verbrauch` не затрагивались;
- структура метаданных не менялась.
