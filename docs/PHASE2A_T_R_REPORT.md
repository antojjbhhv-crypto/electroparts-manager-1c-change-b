Попытки 14:29:00 и 14:29:11 не являются вызовами с payload T-R: значения, введённые через UI Automation (`ValuePattern.SetValue`), не попадали в данные управляемой формы — форма отправляла ранее зафиксированный payload T-I3, поэтому получала идемпотентный ответ и откат.
