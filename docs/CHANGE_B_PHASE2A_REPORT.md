## Причина остановки

CHANGE_B_FINAL_TECHNICAL_SPEC.md (§2-4) не определяет детали, необходимые для серверной реализации:

1. Соответствие знака `Изменение` типу компенсирующего документа (`Wareneingang` приход / `Verbrauch` расход) не задано.
2. Состав реквизитов создаваемых документов (дата, номер, шапка `Komponenten`/`Menge`, строки ТЧ) не специфицирован.
3. Не определено, как вычисляется `B(c,t)` и минимум по всем точкам шкалы: запрос остатков на дату, метод границы, период.
4. Не указано, пишет ли `Korrektur` движения сам или через проведение документов; при проведении под тем же ресурсом возможен вложенный захват, запрещённый D10b.
5. Не задан ключ идемпотентности повторной корректировки.

Любая реализация этих пунктов была бы собственным решением, а не исполнением утверждённой спецификации.
