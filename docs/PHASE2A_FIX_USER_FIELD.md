# Phase 2A — исправление поля `Пользователь` в KorrekturJournal

**Статус: `FIX_VERIFIED_IN_ISOLATED_COPY`.**

- Дата: 21.11.2026
- Источник замечания: независимый аудит (`PHASE2A_INDEPENDENT_EVIDENCE_AUDIT.md`, раздел 2)
- Общий статус Phase 2A на основании этого исправления не повышается.

## Проблема

В `KorrekturJournal` поле `Пользователь` пустое во всех записях, хотя модуль его заполняет.

## Причина

В конфигурации **нет справочника `Пользователи`** (`work-config\Catalogs` содержит только `Komponenten` и `Lieferanten`). База работает в режиме без списка пользователей, поэтому `ИмяПользователя()` возвращает пустую строку — её и записывал модуль.

Поле в регистре — `Строка(100)`, ограничение ни при чём.

## Исправление

`ObjectModule.bsl`:

- заполнение заменено на `Запись.Пользователь = ИмяТекущегоПользователя();`
- добавлена функция с последовательными подстановками:

```bsl
Функция ИмяТекущегоПользователя() Экспорт
	Имя = СокрЛП(ИмяПользователя());
	Если Имя <> "" Тогда
		Возврат Имя;
	КонецЕсли;
	Попытка
		Сеть = Новый COMОбъект("WScript.Network");
		Имя = СокрЛП(Сеть.UserName);
		Сеть = Неопределено;
	Исключение
		Имя = "";
	КонецПопытки;
	Если Имя <> "" Тогда
		Возврат Имя;
	КонецЕсли;
	Возврат "НеОпределён";
КонецФункции
```

Порядок: имя пользователя ИБ → имя пользователя ОС (WScript.Network) → литерал `НеОпределён`. Ошибка COM перехвачена, на проведение не влияет.

Новая версия модуля: SHA-256 `255b72bfdbf9f0ad1271c566c1eed0ab310299f714a7e3662ff8c09ee0f0840b` (6456). Форма и `Form.xml` не менялись.

## Ограничения

- Резервный источник имени ОС (`WScript.Network`) отдельным тестом не проверялся. При этом в проверочной операции он фактически сработал: `ИмяПользователя()` в этой базе пуст, значит значение `TEST_USER` получено именно из резервного пути, а не из первого источника.
- Исторические записи с пустым `Пользователем` не изменялись.
- Основная `test-ib-d3` не обновлялась и сохраняется неизменной.
- Новая операция `000000011` не включена в исходный восьмиоперационный evidence snapshot.
- Исправление не влияет на идемпотентность и остатки — только на авторство записи.

## Что осталось решить

Копия проверки доказывает работоспособность исправления, но основная база работает на прежней версии модуля. Чтобы исправление действовало в `test-ib-d3`, нужно загрузить туда `work-config`: в базе появится новая версия конфигурации, evidence snapshot перестанет соответствовать прогону и потребуется отдельная фиксация.
